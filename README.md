RCB Fanpage
A fan-made website built as my first hands-on project while learning frontend web development.
This project was an opportunity to explore how HTML, CSS, and JavaScript work together to create an interactive website.

⭐️Live Demo - visit the RCB Fanpage at: https://basundhara-07.github.io/RCB-Fanpage/

⭐️Features
* RCB-inspired website design
* Custom page layout and styling
* Image assets and visual elements
* JavaScript-powered interactions

⭐️Technologies Used
* HTML5
* CSS3
* JavaScript
* GitHub Pages for deployment

⭐️What I Learned
* Structuring webpages using HTML
* Styling and arranging elements using CSS
* Adding interactive behaviour with JavaScript
* Organizing assets and project files
* Deploying a static website with GitHub Pages

⭐️Run Locally
1. Clone this repository.
2. Open index.html in your browser.
git clone https://github.com/basundhara-07/RCB-Fanpage.git
cd RCB-Fanpage
